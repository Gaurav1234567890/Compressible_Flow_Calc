# About The Code
This code allows the user to calculate various quantities in the area of high-speed, compressible flows using a GUI.
There are calculators for isentropic, normal, and oblique shock relations in the code. 
This project was mainly for my understanding of the topics and a fun(?) way to apply some classroom knowledge.
This is also my first finished project that I posted on GitHub, so I have no clue if I'm doing this right.
# How to use the Code
Currently, the way to run the code is to download both Calculation.py and main.py and run main.py. Alternatively, you could download and run Run_cfc.bat.
